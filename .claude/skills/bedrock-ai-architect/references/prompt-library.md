# Prompts de trabajo

## Add-on desde cero

“Usa Bedrock AI Architect. Audita la versión instalada y la documentación de esa build. Crea una especificación, matriz de compatibilidad, plan de assets y pruebas antes de programar. Implementa en módulos, valida después de cada fase y prepara el .mcaddon.”

## Objeto mágico de apoyo

“Crea un artefacto mágico original de apoyo, no ofensivo, con modelo 3D propio, icono separado, animación de uso y tres funciones útiles para exploración/construcción. Cada función debe tener cooldown, feedback visual y partículas por capas. No generes sonidos: deja los eventos/referencias documentados para que yo añada audio. Comprueba que la API existe para mi versión de Bedrock.”

## Compañero pacífico

“Diseña un compañero original que siga al jugador, espere órdenes, recoja recursos permitidos y ayude en construcción sin atacar ni causar daño. Define estados, memoria limitada, navegación, distancia máxima, recuperación y límites de rendimiento. Añade modelo, animaciones y VFX no invasivos.”

## Revisión de compatibilidad

“Revisa este proyecto para Bedrock 1.21 temprano y Bedrock 26.60. Distingue APIs y formatos. Indica qué archivos son compartibles y qué partes necesitan builds/perfiles separados. No cambies manifests hasta explicar el plan.”

## Optimización móvil

“Perfila este add-on para Android. Identifica emisiones por tick, texturas grandes, geometría excesiva, entidades activas y trabajo repetido. Propón cambios medibles y no elimines características sin registrar el impacto.”
