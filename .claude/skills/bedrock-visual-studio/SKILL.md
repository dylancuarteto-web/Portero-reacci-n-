# Bedrock Visual Studio
- Conserva exactamente los nombres e identificadores indicados por el usuario.
- Confirma la versión Bedrock objetivo antes de generar archivos nativos.
- Trata los JSON exportados por el panel como especificaciones de diseño, no como formatos nativos garantizados.
- Convierte al esquema oficial compatible y valida JSON, UUID, rutas, dependencias y Molang.
- Separa Behavior Pack y Resource Pack.
- Distingue archivos generados, validados estáticamente, previsualizados y probados en Minecraft.
- No afirmes pruebas que no se hayan realizado.
