# Notas técnicas V7

- Snowstorm es una referencia adecuada para diseñar partículas Bedrock.
- `@minecraft/server-ui` proporciona formularios de diálogo; no equivale a botones táctiles flotantes arbitrarios persistentes.
- Claude Code Skills son instrucciones y recursos. El panel visual es una aplicación HTML aparte.
- MCP conecta herramientas; no es el editor 3D. Blockbench MCP requiere Blockbench y entorno de escritorio.
- En Android se puede abrir el panel local, exportar PNG/JSON y preparar archivos; la integración de escritorio y las pruebas de juego requieren su entorno correspondiente.
